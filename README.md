# 🌿 VisNova — Wellness & Bienestar Natural

**VisNova** es una landing page y catálogo web ligero, elegante y moderno diseñado para una marca de productos de bienestar, aromaterapia, suplementación botánica y cuidado personal holístico.

---

## ✨ Características

- **Diseño Wellness & Minimalista**: Paleta armónica inspirada en la naturaleza (verde salvia, tonos arena/lino y toques terracota).
- **Tipografía Elegante**: Combinación de *Playfair Display* (títulos refinados) y *Outfit* (lectura moderna y limpia).
- **Estructura Rápida y Ligera**: Creada con HTML5, CSS3 y JavaScript nativos, sin frameworks pesados ni dependencias externas de imágenes.
- **Interactividad Intuitiva**:
  - Carrito de compras funcional con contador dinámico y alertas emergentes (*toasts*).
  - Suscripción a newsletter con validación y mensaje de bienvenida.
  - Micro-animaciones al interactuar con productos y botones.
- **100% Responsive**: Adaptable a dispositivos móviles, tablets y pantallas de escritorio.

## 🚀 Cómo visualizalo

Puedes abrir el proyecto de manera inmediata:

1. **Directo en el navegador**:
   Haz doble clic en el archivo `index.html` o arrástralo a cualquier navegador web (Chrome, Edge, Firefox, Safari).

2. **Servidor local (opcional)**:
   Si tienes Node.js o una extensión como *Live Server* en tu editor:
   ```bash
   npx serve .
   ```
   o
   ```bash
   python -m http.server 3000
   ```
   Luego abre [http://localhost:3000](http://localhost:3000).
